# SunWire NL

Electrical & sun-blind installer training simulator (NEN 1010, simplified).

This repository holds the **updates** for the program:

- `update.json` – the update file the program checks at every start and every 15 minutes.
- Releases `v<version>` – the Windows installer and the Mac apps.

How to publish a version or force an update: see [UPDATES.md](UPDATES.md).
