# SunWire NL

Electrical & sun-blind installer training simulator (NEN 1010, simplified).

**Play on a phone or tablet (Android / iPhone / iPad):** https://fearless96.github.io/sunwire-nl/

**Android app (APK):** https://fearless96.github.io/sunwire-nl/android/SunWire-NL.apk

This repository holds the phone version (`docs/`) and the **updates** for the desktop program:

- `update.json` – the update file the program checks at every start and every 15 minutes.
- Releases `v<version>` – the Windows installer and the Mac apps.
- `docs/` – the phone / tablet web app (GitHub Pages). `docs/web-version.json`: set `"force": true` to make every open copy reload to the newest version.

How to publish a version or force an update: see [UPDATES.md](UPDATES.md).
